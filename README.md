# Umgänge – umgås med gänget

En mobilanpassad, fristående webbapp med ett slumpmässigt aktivitetshjul och aktivitetsbank för Nora tätort.

## Funktioner
- Säsongsval: vinter, vår, sommar och höst.
- Budget: 50, 100 eller 200 kr per person.
- Antal deltagare och automatisk totalbudget.
- Filter för inne/ute.
- Slumphjul, ny idé och aktivitetsbank med sökning.
- Favoriter sparas lokalt i webbläsaren.
- Logotyp från användarens uppladdade bild och grön/vit/svart färgprofil.
- PWA-grund med manifest och service worker.

## Köra lokalt
Öppna `index.html` i en modern webbläsare. För PWA/offline-funktioner behöver webbplatsen serveras via HTTPS eller localhost.

## Publicera
Lägg upp samtliga filer i roten på ett nytt GitHub-repository. För Netlify kan publiceringsmappen vara repository-roten; ingen byggkommando behövs.

## Viktigt om priser
Alla aktivitetskostnader är uppskattningar per person. Verifiera entrépriser, öppettider, säsongsöppet och tillgänglighet innan besök. Appen ger inte realtidsinformation om verksamheter.
